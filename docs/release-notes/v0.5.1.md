A maintenance release. No plugin behaviour changes: the wire format, configuration surface and label emission are identical to v0.5.0. Everything here concerns what a release ships and how it describes itself.

## Highlights

**Releases now carry a readable SBOM** (#125). Alongside the existing `prometheus-remote-writer-<version>.cdx.json`, every release ships `prometheus-remote-writer-<version>-sbom.html`: one self-contained page listing components and licences, rendered from the same CycloneDX data by [blitsbom](https://github.com/no42-org/blitsbom). Open it in a browser, with no tooling to install and no network needed at view time. It carries a build-provenance attestation like the other assets, so the one file a human is most likely to open is not the only one whose origin cannot be checked.

**The SBOM says who publishes this software** (#127). The modules built by this project declared no originator, so SBOM tooling fell back to the Maven groupId and attributed them to `org.opennms.plugins`, a namespace shared with unrelated plugins. They now declare `No42 (ronny@no42.org)`. Third-party dependencies were never affected and keep their own publishers.

## Fixes

- Release notes are curated rather than a verbatim CHANGELOG dump (#123). The v0.5.0 body shipped at 16 KB and contained a superseded paragraph claiming the plugin cannot expand `${env:NAME}`, which contradicted a headline feature of that same release. The workflow now prefers `docs/release-notes/<tag>.md` and falls back to the CHANGELOG section when no curated file exists.

## Upgrade notes

Nothing to do. This release is a drop-in replacement for v0.5.0.

One change is visible in Karaf: the bundles now carry `Bundle-Vendor: No42 (ronny@no42.org)`, where previously they had no vendor header. It is a side effect of declaring the SBOM originator, is informational only, and affects neither bundle resolution nor wiring. You will see it in `bundle:info`.

## Artifacts

`prometheus-remote-writer-kar-0.5.1.kar`, a CycloneDX SBOM, and the new HTML SBOM report. All three carry SLSA build provenance from `release.yml@refs/tags/v0.5.1`:

gh attestation verify prometheus-remote-writer-kar-0.5.1.kar \
