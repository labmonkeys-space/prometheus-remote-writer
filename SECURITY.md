# Security Policy

## Supported versions

Only the [latest release](https://github.com/labmonkeys-space/prometheus-remote-writer/releases/latest) receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private vulnerability reporting instead: [Report a vulnerability](https://github.com/labmonkeys-space/prometheus-remote-writer/security/advisories/new).
You will get an initial response within 14 days.

When the report is confirmed, a fix lands in a new release and the advisory is published with credit to the reporter (unless you prefer to stay anonymous).
